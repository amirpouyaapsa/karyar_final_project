# بازارینو | پروژهٔ پایانی دورهٔ کاریار · [English README](README.md)

**بازارینو (Bazarino)** یک پروژهٔ طراحی وب‌سایت فروشگاهی است که با استفاده از HTML5 و CSS3 به‌عنوان پروژهٔ پایانی دورهٔ کاریار توسعه داده شده است. هدف این پروژه، طراحی صفحات مرتبط یک فروشگاه اینترنتی فارسی با رعایت اصول HTML معنایی، طراحی رابط کاربری، واکنش‌گرایی و دسترس‌پذیری است.

## پیش‌نمایش زنده

**[مشاهدهٔ وب‌سایت بازارینو](https://amirpouyaapsa.github.io/karyar_final_project/)**

برای مشاهدهٔ نسخهٔ آنلاین پروژه، روی لینک بالا کلیک کنید.

## صفحات پروژه

### ۱. صفحهٔ فروشگاه (`products.html`)

این صفحه محصولات موجود در فروشگاه بازارینو را نمایش می‌دهد و شامل بخش‌های زیر است:

- سربرگ مشترک شامل لوگو، منوی اصلی، نشانگر سبد خرید و لینک ورود.
- مسیر راهنما و بخش معرفی فروشگاه.
- فرم فیلتر محصولات بر اساس دسته‌بندی، محدودهٔ قیمت و امتیاز کاربران.
- فیلد جست‌وجوی محصولات.
- منوی مرتب‌سازی با گزینه‌های جدیدترین، ارزان‌ترین، گران‌ترین و محبوب‌ترین.
- شش کارت محصول شامل تصویر، نام، قیمت، امتیاز و در صورت لزوم نشان ارسال رایگان.
- لینک از کارت‌های محصولات به صفحات جزئیات هر محصول.
- فوتر مشترک شامل شعار فروشگاه، لینک‌های مرتبط و اطلاعات حق نشر.

### ۲. صفحات جزئیات محصولات (`product_projector.html`، `product_iphone.html`، `product_headphone.html`، `product_Omega.html`، `product_kolah.html`، `product_laptop.html`)

این پروژه شامل شش صفحهٔ اختصاصی برای محصولات ویدئو پروژکتور لونوویکس، آیفون تاشو، هدفون گیمینگ اونیکوما، کپسول امگا ویژن، کلاه کاسکت مدل FM و لپ‌تاپ سرفیس سری ۷ است. این صفحات از چیدمان یکسانی پیروی می‌کنند و قابلیت‌های زیر را دارند:

- سربرگ مشترک وب‌سایت و مسیر راهنما.
- گالری تصاویر محصول شامل سه تصویر و یک تصویر اصلی.
- نشان محصول، مانند نشان پرفروش.
- نام محصول، امتیاز کاربران و تعداد دیدگاه‌ها.
- توضیحات و اطلاعات مربوط به ویژگی‌های محصول.
- قیمت محصول و دکمهٔ افزودن به سبد خرید.
- وضعیت موجودی و اطلاعات زمان تقریبی ارسال.
- بخش دیدگاه‌های کاربران شامل نام، امتیاز و متن دیدگاه.
- فوتر مشترک و هماهنگ با سایر صفحات.

### ۳. صفحهٔ ثبت‌نام (`register.html`)

این صفحه فرم ایجاد حساب کاربری را ارائه می‌دهد و شامل قابلیت‌های زیر است:

- سربرگ مشترک وب‌سایت.
- کارت ثبت‌نام همراه با عنوان و توضیحات.
- فیلد ایمیل با اعتبارسنجی HTML.
- فیلد شمارهٔ همراه با الگوی اعتبارسنجی شماره‌های موبایل ایران.
- فیلد رمز عبور با حداقل طول ۸ و حداکثر طول ۶۴ کاراکتر.
- فیلد تکرار رمز عبور.
- دکمه‌های ثبت‌نام و پاک کردن فرم.
- استفاده از ویژگی‌های HTML برای اعتبارسنجی اولیهٔ فرم و تکمیل خودکار ورودی‌ها.
- فوتر مشترک و هماهنگ با سایر صفحات.

## فناوری‌ها و ابزارهای استفاده‌شده


<ul dir="rtl" style="text-align: right; list-style-position: inside; padding-right: 0;">
  <li><strong>HTML5:</strong> ساختاردهی صفحات، استفاده از عناصر معنایی و ایجاد فرم‌ها.</li>
  <li><strong>CSS3:</strong> طراحی رابط کاربری، استایل‌دهی اجزا و چیدمان بخش‌های صفحات.</li>
  <li><strong>Flexbox و CSS Grid:</strong> سازمان‌دهی چیدمان‌ها و تراز کردن عناصر.</li>
  <li><strong>CSS Variables:</strong> مدیریت مقادیر مشترک طراحی مانند رنگ‌ها، فاصله‌ها، شعاع گوشه‌ها و سایه‌ها.</li>
  <li><strong>CSS Reset:</strong> یکسان‌سازی استایل‌های پیش‌فرض مرورگرها با استفاده از فایل <code>reset.css</code>.</li>
  <li><strong>فونت فارسی:</strong> استفاده از فونت متغیر Vazirmatn به‌صورت محلی برای بهبود خوانایی محتوای فارسی.</li>
  <li><strong>طراحی واکنش‌گرا:</strong> سازگار کردن چیدمان فروشگاه با اندازه‌های مختلف صفحه‌نمایش با استفاده از Media Queryهای CSS.</li>
  <li><strong>حالت تاریک:</strong> پشتیبانی از طرح رنگی سیستم‌عامل با استفاده از Media Query مربوط به <code>prefers-color-scheme: dark</code>.</li>
  <li><strong>Git و GitHub:</strong> کنترل نسخه و میزبانی مخزن پروژه.</li>
</ul>

## ویژگی‌های فنی

- پشتیبانی از زبان فارسی و جهت نوشتار راست‌به‌چپ (`RTL`).
- استفاده از عناصر معنایی HTML مانند `header`، `nav`، `main`، `section`، `article`، `aside` و `footer`.
- اتصال برچسب‌ها به فیلدهای فرم برای بهبود دسترس‌پذیری.
- استفاده از ویژگی `alt` برای ارائهٔ متن جایگزین تصاویر محصولات.
- استفاده از ویژگی‌های اعتبارسنجی فرم مانند `required`، `pattern`، `minlength` و `maxlength`.
- طراحی یکپارچهٔ سربرگ، منوی اصلی و فوتر در صفحات پروژه.
- استفاده از فایل‌های CSS جداگانه برای صفحهٔ فروشگاه، صفحات جزئیات محصولات و صفحهٔ ثبت‌نام.
- چیدمان واکنش‌گرا، از جمله شبکهٔ محصولات با قابلیت سازگاری با صفحه‌نمایش‌های کوچک‌تر.
- استفادهٔ مجدد از متغیرهای CSS برای رنگ‌ها، فاصله‌ها، شعاع گوشه‌ها و سایه‌ها.
- تعریف حالت‌های Hover و Focus برای عناصر تعاملی.
- استفاده از تصاویر محصولات و فایل فونت Vazirmatn به‌صورت محلی.
- استایل‌دهی حالت تاریک بر اساس تنظیمات سیستم‌عامل کاربر.

## نحوهٔ اجرای پروژه

از آنجا که این پروژه با HTML و CSS ساخته شده است، برای اجرای اولیه به نصب وابستگی‌ها یا راه‌اندازی سرور نیاز ندارد.

۱. مخزن پروژه را از GitHub کلون کنید یا آن را دانلود کنید.  
۲. فایل‌های HTML را در کنار پوشه‌های `css`، `font` و `assets` نگه دارید و ساختار مسیرهای نسبی را تغییر ندهید.  
۳. فایل `products.html` را در مرورگر باز کنید.  
۴. از طریق لینک‌های وب‌سایت به صفحات جزئیات محصولات و صفحهٔ ثبت‌نام بروید.

## محدودیت‌های نسخهٔ فعلی

این پروژه یک نمونهٔ اولیه از رابط کاربری سمت کاربر است. در نسخهٔ فعلی:

- جست‌وجو، فیلتر کردن و مرتب‌سازی به منطق اجرایی سمت کاربر متصل نشده‌اند.
- افزودن محصولات به سبد خرید هنوز عملکرد واقعی ندارد.
- سیستم ثبت‌نام به سامانهٔ احراز هویت یا پایگاه داده متصل نیست.
- تطبیق رمز عبور با فیلد تکرار رمز عبور به اعتبارسنجی سفارشی نیاز دارد.
- لینک‌هایی که با `#` تعریف شده‌اند، هنوز به صفحات یا قابلیت‌های واقعی متصل نشده‌اند.

## هدف آموزشی

این پروژه با هدف به‌کارگیری مفاهیم HTML و CSS در طراحی یک وب‌سایت فروشگاهی عملی توسعه داده شده و پروژهٔ پایانی دورهٔ کاریار است. تمرکز پیاده‌سازی بر ساختار معنایی صفحات، طراحی فرم‌ها، چیدمان واکنش‌گرا، استفادهٔ مجدد از استایل‌ها، اصول اولیهٔ دسترس‌پذیری و ایجاد رابط کاربری یکپارچه است.
